# PHP compatibility backlog

This is the active implementation checklist for the previously identified ten gap areas. Every category remains **partial** until its listed work is implemented and verified. Recent additions (string comparison/reverse/search helpers, `strtr`, `strstr`/`strchr`, JSON flags and error helpers) reduce some gaps but do not close their categories.

## Runtime performance and asynchronous execution

- [ ] Replace per-request synchronous VM execution with resumable execution that can suspend during non-blocking I/O. The current VM uses a synchronous instruction loop and `Rc<RefCell<_>>` PHP values, so it cannot be moved directly into Tokio tasks or awaited across I/O. CPU-bound execution still needs a bounded worker pool.
- [ ] Reduce repeated parse/compile work and establish workload-based throughput/latency measurements. The web server now retains compiled bytecode per blocking worker while source dependency content fingerprints and Composer scan-directory entry snapshots remain unchanged; included PHP files, Composer manifests, scanned class files, and directories containing PSR classes all participate in invalidation. A release-mode benchmark compares compile-on-every-request and warm worker-cache execution, reporting requests/second and p50/p95 latency. An initial Linux x86_64 sample on `examples/classes.php` measured 69.2 vs 159.3 requests/s (2.30x). A later release run with 300 iterations over `classes.php`, `arrays.php`, and `json.php` measured 2.51x, 2.39x, and 2.92x speedups respectively; details are in [`docs/performance.md`](performance.md). Representative application/server workloads and repeated runs remain necessary. Cache entries remain worker-local.
- [ ] Bound overload with backpressure. The server now stops polling `accept()` when its in-flight semaphore is full and asks the OS for a 1,024-socket TCP listen backlog, letting short connection bursts wait without allocating unbounded application tasks or immediately returning `503`. The effective queue depends on the OS backlog limit; clients can still fail when that queue fills. This does not free a PHP worker during blocking database or filesystem operations.

For a broader comparison against the official PHP Manual, see the [manual coverage audit](php-manual-coverage.md). It identifies additional language/runtime families and explains why full extension parity needs a pinned PHP release and extension profile.

## 3. Arrays and references — partial

- [ ] Implement PHP-compatible copy-on-write and complete array element reference behavior. Value arrays currently clone by value, isolate nested ordinary writes, and preserve shared embedded reference cells across copies. Regressions verify `sort()`, by-reference `array_walk()`, and by-reference `foreach` on copies detach ordinary slots while retained reference cells and the loop variable's final alias behave correctly; assignment through a whole-array alias also detaches a previously copied snapshot. `array_pop()` and `array_shift()` now return dereferenced values rather than leaking a removed slot's reference cell; regression now also verifies `array_shift()` preserves references in remaining elements while reindexing numeric keys. `array_values()`, `array_filter()`, and `array_column()` preserve embedded reference cells in retained values. `iterator_to_array()` preserves reference-backed elements from arrays and reference-returning generators, including last-value replacement for duplicate keys. Writable untyped object-property destructuring targets and offsets rooted at them now bind by reference; targets already aliased to another variable can be rebound from a reference-bearing destructuring source while leaving the former alias intact. Typed/readonly and overloaded-property targets remain unsupported. Behavior across all built-ins and warning/reference edge cases remains incomplete.
- [ ] Support reference-required callbacks consistently across array callback functions. Callback diagnostics and temporary-argument semantics are covered for all registered callback APIs, including public static method strings. Callback arguments are dereferenced before dispatch so a by-reference callback parameter cannot mutate a reference-backed source slot; `array_walk()` and `array_walk_recursive()` retain their intentionally writable value parameters. Reference warnings are emitted only when that callback is invoked, including the conditional key-comparator paths in diff/intersection variants. `array_walk_recursive()` detects self- and mutually-referential array cycles, emits one filtered warning per call, and stops at the repeated edge. Callback-reference diagnostics for empty array callback operations and zero-comparison sorts are suppressed because no callback invocation occurs.
- [ ] Expand `Traversable` handling and PHP-compatible comparison/sort flags and edge cases. Iteration helpers now consume user `Iterator` and `IteratorAggregate` objects, and callback APIs accept invokable objects; `count()` accepts `Countable` objects and dispatches `Countable::count()`, while array comparator/sort details and iterator edge behavior still need broader coverage. `foreach` preserves arbitrary object/array keys from user `Iterator::key()` and ordinary object public-property order; public plain-object properties and user Iterator/IteratorAggregate chains support by-reference iteration when values are reference-backed. Scalar/null foreach inputs warn and skip. `iterator_count()` counts without converting/reading iterator keys. `iterator_to_array()` converts null, bool, float, and numeric-string keys as PHP array keys do; object/array keys emit `Illegal offset type` warnings and are skipped, while `preserve_keys: false` reindexes values without reading keys. By-reference foreach over plain objects includes visible protected/private properties in class scope and writes through those slots; other iterator edge cases stay open. Descending built-in sorts retain PHP 8 stable order among equal values; `SORT_REGULAR` compares numeric strings numerically, nested arrays by count/key/value, and same-class objects by property keys/values recursively; `array_unique()` and `ksort()`/`krsort()` honor their comparison flags. `SORT_STRING | SORT_FLAG_CASE` and `SORT_NATURAL | SORT_FLAG_CASE` now fold ASCII letters only, matching PHP 8.2+ behavior. Recursive array/object comparison now raises catchable `Error`; `max()`/`min()` share the regular comparator for same-class object properties, including declared property order and nested values. Objects from different user classes are treated as incomparable for array sorting and extrema; stable sorting and equal extrema preserve first-seen order. `SORT_LOCALE_STRING` now calls native `strcoll()` under the active process locale, and `array_multisort()` routes locale mode through normal string conversion including `Stringable`; PHP `setlocale()` remains unsupported, as do internal objects with custom comparison handlers and other comparison edge cases.
- [ ] Complete `range()` warning/notice/error distinctions and remaining array operation diagnostics. `range()` now follows PHP 8.3 numeric-string versus byte behavior for direct and reference-backed endpoints, integral-float steps, decreasing negative steps, and catchable `ValueError`/`TypeError` for invalid inputs; warnings cover empty bounds, multi-byte nonnumeric bounds (with PHP's single-byte/subsequent-bytes wording), implicit numeric casts, and float character-range steps. UTF-8 endpoints use PHP's first-byte behavior, with invalid standalone bytes represented lossily. Array mutators now report PHP-style by-reference diagnostics for literals passed to `array_push()`, `array_pop()`, and sorting, including named `array:` calls, and these failures are catchable as `Error`. Array/object offset keys now raise catchable `TypeError: Illegal offset type` for reads and writes; `isset()`/`empty()` raise `TypeError: Cannot access offset of type TYPE in isset or empty` for array/object keys, emit PHP 8.5 warnings for invalid string-offset keys, and `unset()` raises a catchable `Error` with `Cannot unset offset of type TYPE on CONTAINER` (per the [PHP 8.5 warnings RFC](https://wiki.php.net/rfc/warnings-php-8-5)). `array_multisort()` reports catchable `ValueError` for mismatched column sizes and unknown sort flags, plus `TypeError` for non-array input and repeated sort-order/sort-flag kinds. `array_splice()` casts object replacements to their property values while preserving reference cells in replacement arrays. `array_flip()` and `array_count_values()` now dereference values, warn for each invalid type, and skip invalid entries. `array_fill()` throws catchable `ValueError` for counts outside PHP's supported range and `Error` when generated integer keys overflow; the runtime retains a separate one-million-entry allocation guard. `array_chunk()` throws catchable `ValueError` for zero/negative lengths. PHP 8.5 scalar/resource destructuring now warns and assigns `null` to targets, while `null` stays silent and object destructuring throws `Error`; missing keys in array destructuring also warn and assign `null`, while omitted positions remain silent. `count(..., COUNT_RECURSIVE)` now detects reference cycles, emits one filtered warning, and returns a finite partial count. Fractional floats used as array keys now truncate toward zero and emit the PHP 8.1+ precision-loss deprecation. Warning location and other array diagnostics remain.
