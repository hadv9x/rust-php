# Object-oriented features

This document describes the OOP subset implemented by this project. It is a status guide, not a claim of full PHP compatibility.

User classes can declare non-static, zero-argument `__destruct()` methods with public, protected, or private visibility; constructors and destructors cannot declare return types. The runtime invokes remaining registered destructors in reverse object-creation order during script shutdown. User-function, constructor, instance/static/parent method, closure, callable-array, clone, destructor, string-conversion, magic-property, and property-hook frames destroy objects whose final reference was local when the call returns, while an object returned from the call stays alive. Supported user frames also release local objects while unwinding thrown exceptions and return-type errors. Explicit `unset()` invokes a destructor when it removes the last variable reference from a variable, nested array element, object-property array element, or static-property array element. Reassignment of variables, direct object/static properties, array slots, and array-offset destructuring targets invokes destruction when the overwritten value loses its last reference, including aliases held by copied arrays. Generator frames retain locals while suspended, then release them when they complete or unwind an uncaught exception; yielded values remain available to the caller. Property-hook lifetime behavior is covered for normal return, exceptions, and return-type errors; explicit `gc_collect_cycles()` collection now identifies unreachable object cycles through nested arrays, closure captures, and suspended generator state, invokes destructors once before breaking cycles, and preserves externally rooted or resurrected objects; automatic threshold-based collection and some other VM-held cycle edges remain incomplete.

Anonymous classes support constructor arguments, properties, methods, `extends`, `implements`, and trait composition with adaptations. Attributes in `new #[...] class {}` declarations are retained and available through `ReflectionClass` when given the object. Values from the surrounding scope are passed through constructor arguments, as in standard PHP; lexical `use (...)` capture syntax belongs to a draft RFC and is not part of the PHP language reference. Broader class reflection gaps remain.

## Implemented subset

- Classes, single class inheritance, `new`, constructors, instance/static methods, `self::`, `parent::`, and late-static `static::` for method/property/constant lookup and `new static()`.
- `new stdClass()` creates an empty standard object that accepts dynamic properties; constructor arguments are rejected.
- Anonymous classes with constructor arguments, properties, methods, one parent, and implemented interfaces.
- Public/protected/private access checks for properties, methods, constructors, and class constants.
- Instance/static properties, scalar defaults, scalar/nullable/class property type checks, readonly instance properties, and constructor property promotion. `??` and `??=` treat directly accessible uninitialized typed instance/static properties as unset, including computed and nested property array paths; property coalescing invokes `__isset()` before `__get()` for inaccessible/overloaded names. Direct reads still raise the uninitialized-property error.
- Basic PHP 8.4 instance property `get`/`set` hooks and asymmetric setter visibility are parsed and executed; hook validation, backed-property edge cases, and complete PHP property-hook semantics remain incomplete.
- Traits can declare instance and static properties; each class using a static trait property gets an initialized class storage slot, and trait methods can read/update it through `self::$property`.
- Optional method and constructor parameters with scalar literal defaults.
- Scalar class constants, visibility, final constants, and interface constants.
- Abstract/final classes and methods.
- Interfaces with inherited method obligations and supported parameter/return variance checks. Overrides and implementations may make required parameters optional and append optional parameters; required extra parameters remain incompatible. The built-in `Countable` contract requires a public instance `count()` method with no required arguments; a declared return type must be `int`.
- `instanceof` checks an object against a named class/interface or runtime class-name variable, including parent classes and implemented interfaces; `self`, `parent`, and late-bound `static` are supported in methods.
- `get_class()` and `get_parent_class()` inspect object/class names and use the active instance/static class when called without an argument inside a method.
- Class, interface, enum, trait, method, property, class-constant, global-constant, method-parameter, named-function, and anonymous-class attributes with constant positional/named arguments are retained and exposed through the corresponding reflection APIs, including `ReflectionFunction::getAttributes()`, `ReflectionMethod::getParameters()`, and `ReflectionParameter::{getName,getPosition,getAttributes}`. `ReflectionParameter` also reports type, nullability, default value availability/value, optional/variadic status, and by-reference passing for reflected named functions and methods; `allowsNull()` follows nullable types and explicit null defaults, and untyped parameters allow null; `isOptional()` reflects defaults and variadic declarations; required-after-optional parameter declarations remain rejected by the compiler. Missing defaults raise `ReflectionException`. Contract checked against the [ReflectionParameter manual](https://www.php.net/manual/en/class.reflectionparameter.php) and [`allowsNull()` manual](https://www.php.net/manual/en/reflectionparameter.allowsnull.php). `ReflectionAttribute::{getName,getArguments,getTarget,isRepeated,newInstance}` and `Attribute::TARGET_*`, `TARGET_ALL` (127), and `IS_REPEATABLE` (128) include PHP 8.5 `TARGET_CONSTANT` (64); target and duplicate-use checks cover global constants and class-like declarations. `ReflectionConstant` exposes `getName()`, `getValue()`, `getNamespace()`, `getAttributes()`, and the basic user/internal/deprecated predicates for global constants. Closure parameter reflection and the full Reflection API remain incomplete.
- `is_a()` tests object ancestry/interface membership and supports class-name strings when `allow_string` is true.
- `is_subclass_of()` checks parent-class and interface relationships, returns false for an object's own class, and accepts class-name strings only with `allow_string: true`.
- `property_exists()` reports declared inherited instance/static properties and present dynamic object properties regardless of the property's visibility or value. Undeclared dynamic properties on user objects can be read, written, and unset; `__get`, `__set`, and `__unset` still handle unknown properties when defined.
- Traits with property/method composition, `insteadof`, aliases, and visibility adaptations.
- Shallow object cloning with `__clone()`. During the hook and methods it calls, readonly properties are unset on the clone and may be initialized once from their declaring-class scope, matching PHP 8.3 readonly cloning; other shallow/deep clone edge cases remain open.
- Arithmetic, modulo, concatenation, and bitwise compound assignments on instance properties, routed through visibility/type checks and `__get`/`__set` where applicable.
- `??=` on instance properties, with short-circuit reads and writes routed through `__get`/`__set` when needed.
- Prefix and postfix increment/decrement of overloaded properties read through `__get()` and write through `__set()`; regression and `examples/classes.php` verify getter/setter order and resulting values.
- Arithmetic, modulo, concatenation, and bitwise compound assignments plus `??=` on static properties, using the declaring property's inherited storage slot and type checks.
- Magic property methods `__get`, `__set`, `__isset`, `__unset`; dynamic method hooks `__call`, `__callStatic`; `__invoke` for direct object calls and array callback APIs; and `__toString` for echo and string conversion. Under the runtime's weak scalar behavior, scalar `__toString()` results are converted to strings; array/object results raise a catchable `Error`. The compiler validates public/non-static `__invoke()` and public/non-static/zero-argument `__toString()` declarations, plus requires any declared `__toString()` return type to be `string`; complete magic-method signature validation and error timing remain incomplete.
- Reads of inaccessible typed properties through `__get()` check the returned value against the declared property type, whether the getter returns by value or by reference; incompatible values raise `TypeError`.

## Known gaps

- Intersection and DNF declarations are supported, and interface variance checks split union/intersection members only at the outer expression level, including parenthesized DNF types. Override/interface checks allow required parameters to become optional and allow appended optional parameters; required added parameters remain incompatible; variadic parameters may replace one or more compatible trailing parameters. Constructors skip signature compatibility checks, and private parent methods do not constrain child declarations except final private constructors. Complete PHP variance and late-static binding remain partial. Method parameter and return checks resolve `self` and `parent` against the declaring class, and resolve `static` return types against the runtime called class for regular methods, static calls, parent calls, and callable arrays. Typed instance/static properties resolve `self` and `parent` against the declaring class, including trait properties against the consuming class. Other late-static contexts remain incomplete. Basic union types are supported for method parameters, returns, and properties.
- Multiple inheritance is not supported for classes. Nested trait composition validates missing adapted methods, traits named outside the composition, and unresolved method conflicts even when the composing trait is not yet used by a class. Adaptations track the immediate provider through nested traits, including an alias for a method excluded by `insteadof`; visibility-only adaptation of an excluded method leaves the selected implementation intact. PHP 8.3 `as final` method adaptations are supported for direct, aliased, nested, and anonymous-class uses; they mark only the imported method or alias final, and inherited classes cannot override it while the consuming class can still override its own imported method. Trait properties and class constants compose recursively; duplicate properties must match visibility, staticness, type, readonly state, setter visibility, and supported constant defaults, while duplicate constants must match visibility, finality, type, and value. Property-hook compatibility, attributes on coalesced trait constants, and repeated trait-use declarations remain incomplete.
- Redeclared non-private properties in child classes must keep the inherited type and readonly status; type expressions compare structurally, so union/intersection member order and nullable shorthand do not change the type. Read and set visibility may each stay the same or widen, and defaults may differ. `private(set)` properties are final. Private parent properties are independent and may be redeclared with another type.
- Same-named private parent/child properties now occupy distinct storage slots; methods in each declaring class and their by-reference calls select the correct slot.
- Constructor and method reference parameters/returns support variables, array elements, accessible untyped instance properties, direct static properties, and nested array offsets rooted at static properties; direct alias binding to nested static-property offsets is also supported. Private instance properties from their declaring scope and nested offsets rooted at fixed-name properties are supported. Direct references to typed properties and readonly properties raise PHP-specific catchable errors; overloaded typed-property reads through a reference-returning `__get()` check the getter's current value. Dynamic/inaccessible property paths and broader overloaded-property reference behavior remain incomplete. Destructors run at shutdown and on last-reference `unset()` for supported variable, array, object-property-array, and static-property-array slots; some reassignment paths and automatic cycle-collection timing remain incomplete; explicit `gc_collect_cycles()` supports unreachable object-property cycles, including links nested in arrays, as described above. Dynamic class/interface/trait autoloading supports registered callbacks and the default SPL path loader; broader reflection APIs and magic methods beyond the implemented set remain incomplete. Unit and backed enums are supported with validation gaps. Composer PSR-4, classmap, and PSR-0 mappings are preloaded by the CLI/server when `vendor/autoload.php` is required; dynamic include return behavior remains unsupported.
- `isset()` supports multiple variables, array offsets, and object properties, including nested static or computed property names such as `isset($object->{$name}[$key])`; overloaded properties call `__isset()` before `__get()` and check returned array offsets. Fixed-name and computed dynamic property chains, including array offsets between properties, call `__isset()` at each property step and `__get()` only for intermediate properties. Property and array-offset expressions execute only after all earlier chain steps succeed; broader PHP warning/error behavior remains incomplete. Object iteration, cloning with deep/custom property semantics, and serialization are also incomplete.
- Compiler validation checks public visibility, instance/static requirements, parameter counts, and declared parameter/return types across serialization, property-overloading, call, string-conversion, clone, and debug magic methods. `__invoke()` retains its callable-specific argument and return declarations. `var_dump()` dispatches `__debugInfo()`, displays public, protected, and private instance properties otherwise, and prints nested indentation, property counts, stable per-call object IDs, and PHP-style visibility mangling. Serialization hooks, unusual control-character escaping, and complete resource formatting remain open.

On the PHP 8.5 target, applying the built-in `#[Attribute]` marker to an abstract class, enum, interface, or trait fails during compilation. Target mismatches for ordinary user attributes are checked when `ReflectionAttribute::newInstance()` is called.

The exact subset can change as implementation advances. Run the class example with `cargo run -p php-cli -- examples/classes.php` to inspect current behavior.
See [`examples/late-static-types.php`](../examples/late-static-types.php) for `self` and `parent` argument/return checks, late-bound `static` returns, and a catchable return-type failure.

Unit enums implement the built-in `UnitEnum` interface, and backed enums implement both `UnitEnum` and `BackedEnum`. `interface_exists()`, `instanceof`, `is_a()`, and `method_exists()` recognize the interfaces and their core methods (`cases`, `from`, and `tryFrom`). `ReflectionEnum` exposes `getCases()`, `getCase()`, `hasCase()`, and `isBacked()`; case-name arguments accept scalar string coercion and `Stringable` objects, while arrays and other non-stringable objects raise `TypeError`. Returned `ReflectionEnumUnitCase` / `ReflectionEnumBackedCase` objects support `getName()`, `getValue()`, `getEnum()`, `getBackingValue()`, and filtered `getAttributes()`. These case reflection objects also inherit supported `ReflectionClassConstant` behavior: `getDeclaringClass()`, public modifiers, `getType()`/`hasType()` (enum cases have no declared type), and `isEnumCase()`. Enum case attributes retain their arguments and can be instantiated with target and repeatability checks. Looking up an absent name through `getCase()` throws catchable `ReflectionException`. `getBackingType()` returns `ReflectionNamedType` for backed enums and `null` for unit enums; its name, builtin, and nullability getters are supported. Other enum reflection APIs remain incomplete.

`ReflectionClass` supports `isEnum()`, `isInterface()`, `isAbstract()`, `isInstantiable()`, `isCloneable()`, `isFinal()`, `getParentClass()`, `getInterfaceNames()`, `getInterfaces()`, `getTraitNames()`, `getTraits()`, `getTraitAliases()`, `getMethods()`, `hasMethod()`, `hasProperty()`, `getConstant()`, `getConstants()`, `getReflectionConstant()`, `hasConstant()`, `isSubclassOf()`, and `implementsInterface()` for declared types. `isInstantiable()` returns false for abstract classes, interfaces, traits, enums, and classes with non-public constructors. `isCloneable()` returns false for interfaces, traits, enums, and classes with a private `__clone()` method; public/protected and inherited clone methods are inspected. `getReflectionConstant()` returns `ReflectionClassConstant` for inherited or local constants and `false` for a missing name; its `getName()`, `getValue()`, `getModifiers()`, visibility/final predicates, `getDeclaringClass()`, and filtered `getAttributes()` are supported. `ReflectionAttribute::newInstance()` validates the class-constant target and repeatability. Typed constants expose `hasType()`, `getType()`, and `isEnumCase()`; named, union, intersection, and parenthesized DNF types return nested reflection type objects. Compile-time value checks reject incompatible supported constant values, and declarations using the forbidden `callable`, `void`, or `never` types fail compilation, including when nested in a union/intersection. Exact PHP diagnostic wording and other constant-declaration validation remain incomplete. Enum cases have no declared constant type, so `getType()` returns `null` even for backed enums. Constant lookup includes inherited class/interface constants and enum cases; `getConstants()` preserves declaration order and filters with public/protected/private flags `1`/`2`/`4`. `getConstant()` returns `false` when absent and emits a source-located `E_DEPRECATED` diagnostic for missing names, filtered by `error_reporting()` as in PHP 8.5. `getParentClass()` returns a reflection object for a declared parent or `false` for a root class. `getInterfaceNames()` returns inherited, direct, and transitive interface names once each, with inherited interfaces before interfaces declared by the reflected class. `getInterfaces()` returns an associative array of `ReflectionClass` objects keyed by interface name. Trait inspection reports traits used directly by the reflected class or trait, excluding traits used only by a parent class; `getTraits()` returns an associative array of `ReflectionClass` objects keyed by trait name. `getTraitAliases()` returns aliases declared in the reflected class's own trait-use block, keyed by alias name and valued as `TraitName::originalMethod`. `getMethods(?int $filter = null)` returns `ReflectionMethod` objects in declaration order, starting with the reflected class and then its parents; overrides appear once. A non-null filter returns methods having any requested public/protected/private/static/abstract/final modifier. `hasMethod()` searches inherited methods regardless of visibility and compares method names case-insensitively. `ReflectionMethod::__construct()` accepts an object and method, a class name and method, or the legacy `Class::method` string form; the one-string form emits the PHP 8.4 deprecation. Missing methods raise `ReflectionException`. `ReflectionMethod::createFromMethodName()` provides the non-deprecated PHP 8.3+ single-string factory. Constructor and factory contracts checked against the [constructor manual](https://www.php.net/manual/en/reflectionmethod.construct.php) and [factory manual](https://www.php.net/manual/en/reflectionmethod.createfrommethodname.php). `ReflectionMethod` supports `getDeclaringClass()`, `getModifiers()`, visibility/static/abstract/final and constructor/destructor predicates, parameter counts and return-type inspection, plus `invoke()`, `invokeArgs()`, and `getClosure()`. It also supports `hasPrototype()` and `getPrototype()` for parent-class overrides and methods implementing interface contracts; `getPrototype()` raises `ReflectionException` when no prototype exists. `getClosure()` binds an object for instance methods and returns a callable closure for static methods; these closures preserve Reflection access to non-public methods. Invocation supports private/protected and static methods; `invokeArgs()` preserves string keys as named arguments and reference cells for by-reference parameters. Contracts checked against the [invoke manual](https://www.php.net/manual/en/reflectionmethod.invoke.php) and [invokeArgs manual](https://www.php.net/manual/en/reflectionmethod.invokeargs.php). Nullable return types expose the base name and report nullability through `ReflectionType::allowsNull()`. Parameter counts include optional and variadic parameters; required count reaches through the last non-variadic parameter without a default. The parameter-count and return-type contracts were checked against the [ReflectionMethod manual](https://www.php.net/manual/en/class.reflectionmethod.php) and [ReflectionFunction manual](https://www.php.net/manual/en/class.reflectionfunction.php). `ReflectionFunction` and `ReflectionMethod` also expose `isVariadic()` and `returnsReference()`; both expose the inherited `isStatic()` and `isClosure()` predicates, with `ReflectionMethod::isClosure()` always false and closure reflections reporting their static/variadic metadata. Contracts checked against the [ReflectionFunctionAbstract manual](https://www.php.net/manual/en/class.reflectionfunctionabstract.php). Other class/method inspection methods remain incomplete.

`ReflectionClass::getConstructor()` returns a `ReflectionMethod` for a declared or inherited constructor, or `null` when no constructor exists. `ReflectionEnum` inherits this method and returns `null`.

`ReflectionClass` and `ReflectionEnum` expose `getShortName()`, `getNamespaceName()`, and `inNamespace()`. These derive the short name and namespace from the reflected class name, including for namespaced enums. `ReflectionClass::isTrait()` identifies user traits, while the inherited `ReflectionEnum::isTrait()` returns false.

`ReflectionClass::isInstance(object $object)` checks user class ancestry and interface implementation; `ReflectionEnum` inherits it for enum case objects. Non-object inputs raise `TypeError`.

`ReflectionClass::getDefaultProperties()` and the inherited `ReflectionEnum` method return an array of property defaults, including inherited non-private properties, static properties, private properties declared on the reflected class, and `null` for properties without an initializer. The result does not distinguish static from instance properties. `getStaticProperties()` returns current static values only, including inherited non-private and locally declared private static properties; uninitialized typed static properties appear as `null`.

`ReflectionClass::getProperties(?int $filter = null)` returns `ReflectionProperty` objects for declared and inherited non-private properties; private properties declared on the reflected class are included, but ancestor-private properties are omitted. A filter returns properties with any matching visibility, static, or readonly modifier.

`ReflectionClass::isReadOnly()` reports whether the class declaration uses the PHP 8.2 `readonly` modifier; the inherited method is also available on `ReflectionEnum` and returns `false` for enums. Readonly classes require typed, non-static properties and can only extend readonly parents; anonymous `new readonly class` declarations retain the same modifier and property rules.

`ReflectionClass::isAnonymous()` identifies anonymous class instances while named classes and enums return `false`. `getName()` and `get_class()` expose PHP-style anonymous names with source file, line, sequence number, and parent-class prefix where applicable; `getShortName()` returns `class@anonymous` and anonymous classes are not reported as namespaced. Source-location names for source strings use `Command line code`.

Anonymous classes compiled from included and Composer-loaded files receive unique internal IDs across the combined program, while reflection names retain each class's defining path and local source line.

`ReflectionClass::isIterable()` and the legacy `isIterateable()` alias return whether the reflected class implements `Traversable`, including through inherited user interfaces and parent classes; enums and ordinary classes return `false`.

`ReflectionMethod::setAccessible(bool $accessible)` is a no-op on PHP 8.1+ and emits the PHP 8.5 deprecation diagnostic; reflected non-public methods are accessible without changing this flag.

`ReflectionClass::getProperty()` searches the reflected class and inherited non-private properties. It throws catchable `ReflectionException` when the only matching declaration is a private property from an ancestor; a same-named property declared on the reflected class is returned normally.

`ReflectionProperty::setAccessible(bool $accessible)` is a no-op on PHP 8.1+ and emits the PHP 8.5 deprecation diagnostic; private/protected properties remain accessible through `getValue()` and `setValue()` regardless of the flag. `ReflectionProperty::getDeclaringClass()` returns the declaring class for a property obtained through `ReflectionClass::getProperty()`, including inherited properties. `getValue(?object $object = null)` reads static values without an object and instance values from a compatible object, including private and protected properties; instance reads invoke supported `get` hooks, and reading an uninitialized typed property raises an error. `setValue(?object $object, mixed $value)` writes instance and static properties, bypasses visibility, invokes supported instance `set` hooks, and validates declared property types. `getType()` returns the reflected named/union/intersection type or `null`; `hasType()` distinguishes declared typed properties from untyped properties. `getModifiers()` and `isPublic()`, `isProtected()`, `isPrivate()`, `isStatic()`, `isReadOnly()`, `isPrivateSet()`, and `isProtectedSet()` reflect property metadata; the `IS_PUBLIC`, `IS_PROTECTED`, `IS_PRIVATE`, `IS_STATIC`, `IS_PRIVATE_SET`, `IS_PROTECTED_SET`, and `IS_READONLY` constants resolve to PHP's modifier values. `isPromoted()` identifies properties generated from constructor promotion.
`isInitialized(?object $object = null)` checks the reflected static slot or the object's property slot, including typed properties before assignment and after `unset()`; untyped declared properties without an initializer start as `null`. Instance properties require an object; non-null arguments must be objects, and the supplied object must be an instance of the declaring class.
`hasDefaultValue()` recognizes declared and implicit `null` defaults but returns false for uninitialized typed properties and constructor-promoted properties. `getDefaultValue()` returns the default or `null`; calling it when no default exists emits the PHP 8.5 deprecation recommending `hasDefaultValue()`.

Attributes on parameters of named functions, methods, closures, and arrow functions are retained. `ReflectionFunction::getParameters()` now exposes closure and arrow-function parameters, whose attributes can be filtered, inspected, checked for repetition, and instantiated through `ReflectionParameter` and `ReflectionAttribute`. `ReflectionFunction::getAttributes()` also handles closure reflections, returning an empty array when the closure has no function-level attributes.

`ReflectionParameter::getDeclaringFunction()` returns its associated `ReflectionFunction` or `ReflectionMethod`. `getDeclaringClass()` returns the method's declaring class, or `null` for function and closure parameters. Contracts checked against the [getDeclaringFunction manual](https://www.php.net/manual/en/reflectionparameter.getdeclaringfunction.php) and [getDeclaringClass manual](https://www.php.net/manual/en/reflectionparameter.getdeclaringclass.php).

`ReflectionParameter::__construct()` accepts a named function, closure, invokable object, `Class::method` string, or two-item callable array, and selects the parameter by zero-based position or name. The resulting object exposes the same type, default, reference, variadic, optional, attribute, and declaring-callable metadata as `getParameters()`. Missing parameters raise `ReflectionException`. Contract checked against the [constructor manual](https://www.php.net/manual/en/reflectionparameter.construct.php).

`ReflectionParameter::isPromoted()` reports whether a constructor parameter was promoted to a property. Constructor bytecode retains a per-parameter promotion flag, and both method `getParameters()` and direct `ReflectionParameter` construction expose it. Contract checked against the [isPromoted manual](https://www.php.net/manual/en/reflectionparameter.ispromoted.php).

`ReflectionParameter::isDefaultValueConstant()` and `getDefaultValueConstantName()` retain whether a default was written as a named global or class constant and its source-level name. Literal defaults return false/null; requesting the name when no default exists raises `ReflectionException`. Contracts checked against the [isDefaultValueConstant manual](https://www.php.net/manual/en/reflectionparameter.isdefaultvalueconstant.php) and [getDefaultValueConstantName manual](https://www.php.net/manual/en/reflectionparameter.getdefaultvalueconstantname.php).

`ReflectionParameter::canBePassedByValue()` returns false for by-reference parameters and true for ordinary parameters, complementing `isPassedByReference()`. Contract checked against the [canBePassedByValue manual](https://www.php.net/manual/en/reflectionparameter.canbepassedbyvalue.php).

`ReflectionParameter::getClass()`, `isArray()`, and `isCallable()` remain available as deprecated compatibility methods and emit PHP 8.0 deprecation diagnostics. The predicates recognize matching members of union types; `getClass()` returns a `ReflectionClass` for a single named class type and `null` for builtin, union, or untyped parameters. Contracts checked against the [getClass manual](https://www.php.net/manual/en/reflectionparameter.getclass.php), [isArray manual](https://www.php.net/manual/en/reflectionparameter.isarray.php), and [isCallable manual](https://www.php.net/manual/en/reflectionparameter.iscallable.php).

`gc_collect_cycles()` counts and collects unreachable object cycles. It traces direct object properties, objects nested in property arrays, closure captures, and suspended generator frame state when those values are held by the cycle. It preserves externally referenced and destructor-resurrected objects, runs each destructor before breaking collected property cycles, and returns the number of swept objects. Automatic threshold-based collection and some other VM-held cycle edges are not implemented. The zero-argument and integer return contract follows the [PHP manual](https://www.php.net/manual/en/function.gc-collect-cycles.php).

`ReflectionFunction::invoke(...$args)`, `invokeArgs(array $args)`, and `getClosure()` are supported for named functions and closures. `invokeArgs()` treats string keys as named arguments and preserves reference cells for by-reference parameters. `getClosure()` returns the original reflected closure or a callable closure wrapping a named function. Contracts checked against the [invoke manual](https://www.php.net/manual/en/reflectionfunction.invoke.php), [invokeArgs manual](https://www.php.net/manual/en/reflectionfunction.invokeargs.php), and [getClosure manual](https://www.php.net/manual/en/reflectionfunction.getclosure.php).

`ReflectionClass::getMethod()` raises a catchable `ReflectionException` when the requested method does not exist.
`ReflectionClass::getMethods(?int $filter)` and `getProperties(?int $filter)` accept nullable integer filters, weakly convert supported scalar values, and raise `TypeError` for arrays/objects or nonnumeric strings.

Method variance treats user interfaces/classes extending or implementing `Traversable` as subtypes of `iterable` for covariant returns; narrowing an `iterable` parameter to one such subtype remains incompatible. Runtime `iterable` return checks also recognize user classes implementing built-in `Iterator` and `IteratorAggregate` interfaces.

Initialized readonly properties cannot be unset. An uninitialized readonly property can be unset only from its declaring-class scope, as specified by the [PHP properties manual](https://www.php.net/manual/en/language.oop5.properties.php); clone-time readonly reinitialization remains handled by the PHP 8.3 clone path.
