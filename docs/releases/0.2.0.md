# php-rust 0.2.0 — Developer Preview

`php-rust` 0.2.0 is an experimental Developer Preview of a PHP interpreter written in Rust. It provides a command-line runner and an HTTP development server for the documented PHP subset.

## Install

The prebuilt archive in this release targets **Linux x86_64**. Extract it and run `./install.sh`, or build from source with Rust 1.93.1, the toolchain used for release verification:

```sh
cargo install --path crates/php-cli --bins --locked
```

Run a PHP file with `php-rust path/to/file.php`, or start the HTTP server with `php-rust-server --root public --bind 127.0.0.1:3000`. See [CLI and installation](../cli-and-installation.md) and [web server](../web-server.md) guides for setup and options.

## Preview scope

The runtime includes a growing subset of PHP syntax, functions, arrays and references, exceptions, classes and types, generators, JSON, filesystem helpers, a development HTTP server, and selected PDO/database integrations. The [PHP manual coverage audit](../php-manual-coverage.md) and [compatibility backlog](../php-compatibility-backlog.md) list implemented areas and open gaps.

## Known limitations

- This is not a drop-in PHP replacement. Existing applications may depend on syntax, built-ins, extensions, or edge-case behavior that is not implemented.
- No complete PHP language-version or extension compatibility profile is promised by this preview.
- The server is intended for development behind a trusted TLS reverse proxy; it is not PHP-FPM/FastCGI and does not terminate HTTPS directly.
- Sessions are in-memory and are lost on restart; they are not shared between server processes.
- Database support is partial and backend-dependent. See [database support](../database.md).
- Only the Linux x86_64 prebuilt executable package is supported. Other targets have not been validated for release.
- There is no declared minimum supported Rust version. The release workflow is verified with Rust 1.93.1; source builds may work with other toolchains but are not guaranteed.

## Verification

The release workflow uses Rust 1.93.1, checks formatting, runs Clippy, runs the workspace tests and all top-level PHP examples, then packages the Linux x86_64 binaries, Docker image, source archive, and SHA-256 checksums. Clippy passes with 173 informational warning entries on the initial baseline; formatting failures and command/test failures block the workflow. See [build, install, and test](../testing.md).
