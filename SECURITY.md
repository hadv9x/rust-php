# Security policy

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, open a public issue asking for a private reporting route without including exploit details.

Include the affected version or commit, the impact, and steps to reproduce in the private report. Do not include real credentials, personal data, or production database contents.

## Supported versions

This project is experimental and does not currently publish a security support window. Reports against the latest version on the default branch are the most actionable; fixes may not be backported to older versions.
